# RGB Color Comparison Tool

## Description

**version 1.0**

This program allows the user to enter two colors using RGB values. Each color is stored as three values representing red, green, and blue. The program then displays both colors back to the user.

This version is the first step toward creating a tool that can compare colors and determine how distinguishable they may be from each other.

## Example

To compile the program use the command:

```bash
g++ main.cpp -o main
```

to run the program use the command:

```bash
./main
```

Here is an example of the program running:

```text
Enter your R,G,B values for Color 1:
R: 255
G: 0
B: 0
Color 1 RGB: 255, 0, 0

Enter your R,G,B values for Color 2:
R: 0
G: 255
B: 0
Color 2 RGB: 0, 255, 0
```
